The Band
About Kreolyte

Born from the volcanic energy of Mauritius in the Indian Ocean, Kreolyte is a three-piece alternative rock band that channels the intensity of their island home into a sound that defies easy categorisation.

Rooted in the post-grunge and alternative rock tradition of Muse, Red Hot Chili Peppers, and Incubus, the band weaves in the improvisational language of jazz to create music that breathes — tightly controlled one moment, explosively free the next.

After performing at the Underground Rock Festival (URF 2025), Kreolyte heads into 2026 with a concert on 25 July at Madeleine, Rose Hill, sharing the stage with Revolt.

Mauritius has a rich and growing rock underground. Bands like Revolt, Skeptikal, Apostrophe and King of None have been gaining recognition since 2018 — Kreolyte carries that torch forward.

Technical Notes
What's Possible & What's Not

✅ Fully Doable

✓ Website with all tabs — studio, library, videos, shows, about. Fully custom design.
✓ WAV editor in-browser — using the Web Audio API. Cut, trim, loop, save clips, listen while editing.
✓ Equaliser — real-time 8-band EQ via Web Audio API BiquadFilterNode.
✓ Effects — reverb (convolution), delay, chorus, distortion all native in-browser.
✓ YouTube embed — your channel's videos embedded directly on the Videos tab.
✓ Comment section — built-in, or using Disqus/Firebase for persistence.
✓ Sound library — list and play published tracks with waveform display.
✓ Owner-only upload/edit — password-protected admin mode or login system.

⚠ Doable With Backend / Cloud

~ Large file uploads (500MB+) — browsers can handle this with chunked upload to a server (e.g. AWS S3, Cloudflare R2). A free hobby host won't work — you need cloud storage (~$5–15/month for moderate use).
~ Persistent storage — files, comments and saved clips need a database (Firebase, Supabase free tier works).
~ Save multiple cut parts — fully doable in browser session; persisting across sessions needs backend storage.

❌ Hard Limitations

✗ Professional DAW-level editing — browser audio editing is good but not ProTools/Logic level. For mastering, export and use Audacity/Logic.
✗ Real-time collaboration — two people editing the same file simultaneously is complex to build.
✗ Automatic Facebook/YouTube data sync — Facebook's API is restricted; YouTube embed is easy but scraping profile data is against their ToS. Manual input is the practical approach.
