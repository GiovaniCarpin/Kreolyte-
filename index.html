The Band
About Kreolyte

Born from the volcanic energy of Mauritius in the Indian Ocean, Kreolyte is a three-piece alternative rock band that channels the intensity of their island home into a sound that defies easy categorisation.

Rooted in the post-grunge and alternative rock tradition of Muse, Red Hot Chili Peppers, and Incubus, the band weaves in the improvisational language of jazz to create music that breathes — tightly controlled one moment, explosively free the next.

After performing at the Underground Rock Festival (URF 2025), Kreolyte heads into 2026 with a concert on 25 July at Madeleine, Rose Hill, sharing the stage with Revolt.

Mauritius has a rich and growing rock underground. Bands like Revolt, Skeptikal, Apostrophe and King of None have been gaining recognition since 2018 — Kreolyte carries that torch forward.

Technical Notes
What's Real & What's Not

Hosted free on GitHub Pages. The Sounds and General tabs are wired to a real Supabase database — uploads there genuinely persist. The Studio tab's editor is a visual demo of what's buildable next.

✅ Real & Working

✓ Sounds tab — real file upload, saved permanently in Supabase Storage, playable by any visitor.
✓ General tab — real message board, saved permanently in a Supabase table.
✓ Owner password gate — only someone with the password can upload; anyone can listen/read.
✓ YouTube embed — your channel embedded directly.
✓ Gallery & About — your real photos.

⚠ Free Tier Limits

~ Supabase free tier: 1GB total storage. Fine for MP3s/clips, tight for many full-length raw WAVs (those run 400–600MB each). Compressing to MP3 (~5–10MB per song) makes this very comfortable.
~ 500MB+ uploads: possible, but will eat the free tier fast. For large raw masters, Cloudflare R2 (10GB free) is a better fit — ask if you want that added alongside Supabase.

❌ Still a Mockup

✗ Studio tab editing — cut/trim/EQ/effects are visual only right now, not yet wired to real audio processing. Buildable with the Web Audio API as a next step.
✗ Automatic Facebook/YouTube sync — both platforms block scraping; manual updates (like this) are the practical path.
